# Security Policy

Report vulnerabilities privately through
[GitHub Security Advisories](https://github.com/xpxueA/token-pass-swith/security/advisories/new).
Do not open a public issue for an unpatched vulnerability.

Do not disclose API keys, bearer tokens, relay credentials, signing keys,
customer data, or internal infrastructure details. Redact secrets before
sharing logs.

Security fixes are distributed as signed Windows releases. The updater uses
`https://tokenpass.cloud/downloads/token-pass-swith/latest.json`; GitHub
Releases is the public mirror.
